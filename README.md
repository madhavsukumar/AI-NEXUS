RoadWatch AI

AI-Powered Road Hazard Detection & Smart Road Monitoring Platform

RoadWatch AI is a futuristic web-based platform designed to help citizens and authorities identify, report, and monitor road hazards such as potholes, cracks, waterlogging, and debris. The platform uses a simulated AI detection engine, interactive analytics dashboard, and live hazard mapping system to improve road safety and infrastructure maintenance.

🌟 Features
1. AI Hazard Detection
Upload road images.
Simulated AI classifies hazards:
Pothole
Crack
Waterlogging
Debris
Displays:
Hazard Type
Severity Level
Confidence Score
Risk Score
Recommended Action
2. Smart Reporting System
Add location details.
Add reporter information.
Priority override options.
Detection sensitivity adjustment.
3. Real-Time Analytics Dashboard
Total Reports
Critical Reports
High Severity Reports
Average Risk Score
Hazard Distribution Chart
Reports Trend Chart
4. Interactive Hazard Map
Displays hazard locations using Leaflet Maps.
Severity-based color markers.
Visual hotspot identification.
5. Report Management
Stores reports locally using browser Local Storage.
Recent reports table.
Clear all reports functionality.
6. Futuristic UI
Glassmorphism design.
Cyberpunk-inspired theme.
Responsive layout.
Smooth animations and transitions.

🚀 How to Run
Option 1: Direct Browser Launch
Download the project.
Open Roadwatch_finalweb.html.
The application will run immediately.
Option 2: VS Code Live Server
Open project folder in VS Code.
Install Live Server extension.
Right-click Roadwatch_finalweb.html.
Click Open with Live Server.

Road maintenance agencies often depend on manual inspections, leading to delayed hazard detection and increased risks for commuters.

RoadWatch AI addresses this issue by enabling:

Rapid hazard reporting
Automated classification
Severity prioritization
Data-driven maintenance planning
Smart city integration
